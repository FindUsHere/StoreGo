## 📖 Loyiha Haqida

**StoreGo** — bu tadbirkorlar va onlayn savdo egalari uchun maxsus ishlab chiqilgan **innovatsion e-commerce yechimi**! 🚀

Bizning platformamiz orqali siz mijozlarga nafaqat zamonaviy va chiroyli **veb-sayt**, balki qulay **Telegram bot** orqali ham xizmat ko'rsata olasiz. Dasturlash bilimisiz, atigi bir necha daqiqada o'z internet do'koningizni yarating va biznesingizni yangi bosqichga olib chiqing!

## 🛠️ Texnologik Stack

&lt;p align="center"&gt;
  &lt;img src="https://skillicons.dev/icons?i=react,nodejs,postgres,redis,docker,nginx,git,github&theme=dark" alt="Tech Stack" /&gt;
&lt;/p&gt;

- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, Redis (kesh)
- **Bot:** node-telegram-bot-api
- **Deploy:** Docker, Nginx, Cloudflare
- **To'lov:** Click, Payme, Stripe integratsiyasi

npm run dev
